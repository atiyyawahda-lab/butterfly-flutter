# Silver Butterfly Animation 🦋

Project iseng bikin animasi kepakan sayap kupu-kupu perak yang smooth parah. Semuanya digambar prosedural helai demi helai pakai Kurva Bezier Kubik biar kelihatan rapi dan ga kaku.

## Kenapa Project Ini Keren?
- **Proses Loading Estetik:** Pas awal di-run, kamu bisa lihat proses sayapnya digambar satu-satu secara prosedural sebelum dia mulai ngepak otomatis.
- **Auto-Split Screen:** Jendela grafiknya bakal otomatis nempel di sebelah kanan layar monitor, jadi ga bakal nutupin code editor kamu pas lagi debugging.
- **Engsel Anti-Drift:** Pakai perhitungan matematika mutlak biar sayap kanan-kiri posisinya seimbang dan ga bakal melenceng ke kiri.
